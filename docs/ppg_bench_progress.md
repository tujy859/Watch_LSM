## PPG-BP与PulseDB是两份独立数据集

PPG-BP名称中的PPG指光电容积脉搏波，BP指血压。它由桂林人民医院采集，原始数据包括219人、每人3段2.1秒指尖PPG，共657段，采样率1000 Hz；血压标签来自上臂式电子血压计，没有连续ABP波形。详见[PPG-BP原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC5827692/)。

PulseDB则汇集MIMIC-III与VitalDB中的同步PPG、ECG和动脉血压ABP波形；公开全集包括5361人、5245454个10秒片段，统一采样率125 Hz，血压标签从ABP提取。全集规模不表示本机已下载全部数据。详见[PulseDB原始论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9944565/)。

本项目PPG-Bench采用的是PPG-BP，按固定官方代码排除231号后使用218人、654段；此前1750项线性评测结果均属于这份数据。PulseDB属于本项目另行推进的血压评测路线，正式片段映射及完整评测闭环仍待完成，二者进度不能合并。

PulseDB此前已做文件打开、波形/标签抽样读取和数据修复；10月29日已完成38份损坏文件修复、207份AAMI相关文件补齐，并核查AAMI清单243项。尚未完成的是将官方索引中的1340条记录逐条映射到正确片段、实现按需读取的正式数据加载器，以及连接官方训练/校准/测试划分和模型预测。当前`watch_lsm/data/pulsedb.py`与`scripts/evaluate_aami_bp.py`均尚未实现。后续工作重心转向PPG-Bench，其9份数据不含PulseDB，因此没有自动补上这条独立流程。AAMI测试文件已齐全不能替代训练/校准数据覆盖核验；现阶段未推进的主要缺口是实现与验证，不能继续概括为全部数据不可用或必须先租用服务器。

## 评测方法怎么区分

| 方法 | 训练内容 |
| :--- | :--- |
| 线性 | 冻结预训练编码器，仅拟合简单回归/分类预测头 |
| 随机森林 RF | 冻结编码器，拟合随机森林预测器 |
| MLP | 冻结编码器，训练小型神经网络预测头 |
| 全量微调 | 从公开预训练权重出发，编码器和神经网络预测头一起训练 |

“神经网络下游评测”指MLP和全量微调。每个模型、任务、方法需要5个随机种子×5个外层测试折，即25项评测；一项神经网络评测内部还包含调参搜索。

共9份数据、17个主要任务、9个次要任务。主要任务评估全部4种方法，次要任务仅评估线性与RF。

| BIDMC | 呼吸率、血氧饱和度（2项） | 无 | 完成，53人 |
| BUT-PPG | 血糖回归（1项） | 收缩压、舒张压、血氧饱和度（3项） | 完成，50人 |
| RealWorldPPG | 闭集身份识别（1项） | 无 | 完成，35人/2074条采集记录 |
| PPG-DaLiA | 心率、活动分类（2项） | 无 | 完成，15人 |
| ECSMP | SDS抑郁筛查（1项） | 情绪评分回归后分类（1项） | 完成，60人 |

已准备的8份数据均完成50/64/100/125 Hz预处理。RealWorldPPG是按采集记录划分的闭集身份识别；其余任务按上游受试者分组协议执行。

对比对象为**AnyPPG、PaPaGei-S、PaPaGei-P、PulsePPG、SigmaPPG、PRV、MOMENT-1-small**。随机/常数对照随相应评测计算，不另计为第8个需要训练的模型。PPG-Bench不包含PulseDB，本表不能代替项目独立的PulseDB/AAMI评测。

## 已完成与已核验的区别

表中“完成”确认评测结果已经发布。独立检查预测、划分和指标重算，目前覆盖PPG-BP全部1750项，以及BIDMC的AnyPPG和PaPaGei-S共100项；其余已发布结果还需要继续核验。

PPG-BP的7对象收缩压/舒张压线性均值与论文在两位小数上一致；上述BIDMC两对象的呼吸率/血氧均值及95%置信区间也在两位小数上一致。此结论仅限已经核验的范围。
