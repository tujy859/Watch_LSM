# 手表PPG基础模型评测PoC：讨论稿

2026-11-04，Asia/Shanghai。用户明确当前目标为先建立科学严谨、工程轻量的手表PPG基模评测体系，再开展训练研究。本页记录目标及建议实验顺序；具体实验组合属于讨论建议，本轮未启动训练、下载或调整既有队列。

## 目标与结论边界

要检验的问题是：**在什么任务、信号质量、标注量和设备迁移条件下，公开PPG基础模型优于传统方法、通用时序模型和小型任务监督模型？** “能力更强”是待检验假设；未发现增益也应进入报告，并用于决定后续训练方向。

第一版默认使用公开数据、离线计算，主比较输入为单通道腕部PPG。PPG+ACC作为独立扩展，双方对照获得相同输入。手表首先限定信号来源，端侧部署、量化和功耗优化后续再按需要研究。

冻结编码器后拟合Ridge、逻辑回归或小型任务头，属于评测所需适配；小型监督基线同样需要训练。这与后续重新预训练基础模型是不同工作。仅比较预训练模型与滤波器，还不能把全部差异归因于预训练。

PPG-Bench v1在其68组主要任务与方法组合中，报告35.3%未明显优于常数/随机对照，83.8%没有PPG专用模型同时胜过PRV与MOMENT。这支持保留强对照，而非预设普遍优势；它也不证明所有PPG基础模型无效。[原文](https://arxiv.org/html/2610.13435v1)

## 四类任务及首选资源

| 能力 | 建议资源与起点 | 输出与主要评价 | 能支持的结论 |
| :--- | :--- | :--- | :--- |
| 腕部HR与运动鲁棒性，第一优先 | DaLiA；WildPPG腕部绿光通道用于第二数据集评测 | 窗口HR、按受试者汇总MAE、活动/运动强度分层、可输出比例 | 窗口级HR估计及跨数据集迁移；不能推出逐搏准确 |
| 伪影检测与信号质量 | DaLiA+SEGADE；BUT-PPG作为手机采集域的补充 | 逐点mask或窗口质量概率；F1、灵敏度、特异度、AUPRC及覆盖率 | 识别不可靠信号的能力；检测不等于恢复干净波形 |
| 逐搏提点与PRV | DaLiA/WESAD原始连续段，同步ECG；按场景扩展WildPPG | 心搏时刻、间期、Beat F1、间期误差、RMSSD/SDNN偏差与一致性 | 心搏检测、PPG脉率变异性及其与ECG HRV的一致性 |
| 配对去噪与信息保留 | 多受试者高质量PPG加可控噪声；EPFL作为小型补充；真实运动数据做下游验证 | 波形NRMSE/相关性、峰/形态保留、固定下游算法的HR与间期误差 | 合成噪声条件下恢复能力与真实下游收益；合成增益不自动代表真实波形恢复 |

血压与疾病筛查作为表征扩展：先整理已有PPG-BP受试者级结果，后续再接PulseDB官方划分。PPG-BP/PulseDB主要是指端/临床信号，不能独立证明手表血压或疾病筛查能力。疾病任务先检查阳性受试者数量、标签定义及每折覆盖，加入年龄/性别等可用人口学对照，并检验“人口学+PPG”相对人口学的增量；测试标签的直接派生信息不得作为输入。年龄预测本身也不能直接称为血管生物年龄验证。

**提点的范围须明确。** 第一阶段指脉搏峰/起始点及间期。同步ECG可用于心搏对应、漏检/误检和间期一致性评测；脉搏峰、起始点及重搏切迹的绝对定位误差需要PPG自身的参考标注。固定时延校正不能把ECG R峰变成PPG峰真值，也不能未经验证直接作为逐点监督标签。PPG波峰与ECG R峰存在生理时延，PRV与HRV也不完全等价，不能将全部差异都归为模型误差。[PRV与HRV原文](https://pmc.ncbi.nlm.nih.gov/articles/PMC7437069/)

PRV建议以5分钟稳定连续段为主，先评RMSSD/SDNN；60秒RMSSD可另作探索并验证，不从现有8秒HR窗口推断HRV能力，也不拼接不连续片段。同步、异常搏动、缺失与质量剔除规则预先固定。[HRV标准原文](https://www.escardio.org/static-file/Escardio/Guidelines/Scientific-Statements/guidelines-Heart-Rate-Variability-FT-1996.pdf)

## 首轮模型与对照

| 对象 | 选择依据 | 首轮使用方式 |
| :--- | :--- | :--- |
| AnyPPG | 已有权重与适配，ECG引导的预训练路线 | 冻结表征+Ridge/逻辑回归 |
| Pulse-PPG | 野外腕部预训练，贴近手表场景 | 冻结表征+相同类型预测头 |
| PaPaGei-S | 已有可靠加载与历史结果，形态感知路线 | 第三个固定参照 |
| MOMENT-1-small | 已有资产，检验PPG专用预训练是否优于通用时序表征 | 同任务、同标签预算 |
| 传统算法/特征 | HR用成熟峰检测/频谱方法；表征任务用HR、形态及窗口长度允许的变异性特征 | 相同测试样本；学习任务使用匹配预测头 |
| 小型监督CNN | 判断基础模型相对普通任务网络是否有实际收益 | 固定小架构与有限搜索预算，只用同一训练标签 |
| 常数、随机编码器消融 | 检查标签基线与预训练表征的增量 | 常数用训练集统计量；随机编码器与预训练编码器配同一头 |

无需一开始扩展更多模型或穷举所有头。先跑线性探针，核心任务补一个预先限定容量的小MLP检查线性读出限制。随机冻结编码器是消融，不能替代充分训练的小型监督基线；如果要更强地归因于预训练，还需同架构、同下游预算的随机初始化/预训练对照。

现有三个PPG适配器输出窗口级512维表征。波形去噪与逐搏提点需要保留时间分辨率的中间特征和小型解码/检测头；不能假定全局向量已具备这两种输出。优先验证现有模型是否能提供合适的时序特征，再决定是否引入另一个有可用权重的重建模型。[PaPaGei v2](https://arxiv.org/html/2410.20542v2)、[Pulse-PPG v2](https://arxiv.org/html/2502.01108v2)、[AnyPPG固定代码](https://github.com/Ngk03/AnyPPG/tree/661b877aa96eac3bba320a462cb2a3bfea991103)

## 保留的科学约束

1. **受试者隔离及调参隔离。** 按受试者定义划分，再切窗、增强或生成噪声；同一干净信号的所有噪声版本归同一划分。学习的归一化、阈值和选参只用训练/验证。新PoC可采用一套固定的受试者五折，内层固定验证受试者，小网格选参；随机训练或少标签抽样重复3个种子。此为新PoC协议，不覆盖既有论文复现的五种子/完整搜索设置。
2. **比较相同信息与相同测试范围。** 模型可使用原生采样率和必需预处理，但必须记录；相同物理时段、模态和标签预算保持一致。ECG作为参考，不作为PPG-only推理输入。零相位离线滤波不据此声称实时效果。
3. **不隐藏困难片段。** 当前DaLiA上游预处理排除低振幅、混合活动窗口；其官方复现结果应原样保留。新的运动鲁棒性分析需明确样本覆盖，对有有效参考的困难窗口单独检查，并让全部方法面对相同测试集合。拒绝输出时同时报告覆盖率与误差，按活动/质量分层；不得仅凭平均分改善宣称抗噪。
4. **按人估计不确定性。** 保存逐窗口预测和受试者身份，先按人汇总，再汇总同一人的多种子结果，对人的配对误差差值bootstrap。该区间反映固定划分与训练方案下的受试者差异，不涵盖训练集抽样、划分和模型选择的全部不确定性，种子波动另外报告。不能把重叠窗口或多次交叉验证的折/种子当独立患者。小样本结果如区间较宽，应保留不确定结论。预先指定主指标、主要比较和实际有用的差值标准。
5. **预训练暴露单独核查。** AnyPPG预训练明确含PulseDB，PaPaGei预训练包含VitalDB/MIMIC-III等源队列；未经身份映射，不能把这些组合称为完全未见患者评测。用一张模型×数据集小表区分“明确使用”“源队列可能重合”“论文未列入”“未知”。公开论文已用过的下游数据也不称全新盲测。[AnyPPG v4数据说明](https://arxiv.org/html/2511.01747v4)
6. **分别检验抗噪、恢复及生理保留。** 信号质量分数更好不等于形态真实。去噪研究先固定同一峰检测/预测器，比较输入变化产生的收益；重新训练下游模型的结果另列。比较原始输入、传统去噪、学习去噪时，保持划分与参考一致。无干净参考的真实运动PPG不计算所谓真实重建误差。

提点可借鉴[ppg-beats官方实现](https://github.com/peterhcharlton/ppg-beats)与[Charlton等2022原文](https://openaccess.city.ac.uk/id/eprint/28452/8/Charlton_2022_Physiol._Meas._43_085007.pdf)，先选择MSPTD或qppg这类成熟对照；无需把完整Matlab框架迁入本项目。纯PPG与ACC辅助传统算法分开比较。

## 下一步建议与验收产物

**第一里程碑：两份腕部数据的HR表征评测。**

- 复核现有DaLiA/WildPPG已发布预测、受试者划分、标签及腕部通道，复用符合协议的结果；本轮没有重新统计当前完成数量。固定一个PoC样本清单与测试划分，补传统HR算法、小型监督CNN及MOMENT对照。
- 对AnyPPG、Pulse-PPG、PaPaGei-S先做冻结线性探针。核心报告至少含：逐人MAE、活动/运动分层、覆盖率、与强对照的配对差值及置信区间。
- 在固定外层测试受试者上，用相同的嵌套受试者子集画少标签曲线；DaLiA五折可比较3人、6人和全部外层训练受试者的总标签预算，每档预算均包含验证受试者。预先固定每档训练/验证人数，并让各方法共享，报告实际人数与窗口数。不以随机抽窗口模拟新受试者标注减少。
- 另做DaLiA训练/验证后冻结全部选择，在WildPPG评测的单向迁移；不依据WildPPG测试分数挑模型或阈值。该结果与“在WildPPG内重新拟合预测头”的五折结果分别报告，预训练暴露状态一并展示。
- 验收产物为一张主比较表、少标签曲线、活动/噪声分层图及可复算的逐人预测文件。是否优于强对照由结果决定，不能以“必须胜出”验收代码正确性。

**第二里程碑：质量识别与逐搏/PRV。** 核验SEGADE到DaLiA的受试者与时间映射；BUT-PPG若用于SQI须补3,058条Poor波形。使用原始连续数据构建提点与PRV参考，先验证传统算法、同步和标签，再加入基模时序头。质量检测与去噪分别报告。

**第三里程碑：有针对性的去噪与健康表征扩展。** 根据前两步暴露的失败场景决定是否训练去噪头、做域适配或微调。已有PPG-BP结果先作为临床表征辅助；PulseDB官方映射、预训练患者重合和训练/校准/测试覆盖核验后再作正式BP评测。疾病筛查选择一个标签可靠且样本足够的任务，不将现有小样本多个近随机任务包装为筛查能力。

## PoC实现范围

优先复用现有PPG-Bench模型适配、预处理和结果解析。新增工作只需：带受试者/采集记录/时间位置的样本表、固定划分文件、必要的任务评测脚本、逐例预测与指标汇总，以及简短报告。配置、权重版本、种子与输入模态写入每次运行元数据即可；可缓存冻结表征来减少计算。

全套PPG-Bench复现是已有工作线，保留其原协议及产物；完成全部14,625项不是新PoC第一个结论的前置条件。当前也不需要先增加服务平台、网页看板、任务调度系统、重型代码治理或手表端部署。既有运行任务是否调整需结合后续工作安排，本轮未操作进程。
