# PPG模型覆盖 选型依据与Apple和Google论文对照分析

2026-11-05，Asia/Shanghai。基于已发布实验作解释与选型复核，本轮没有新训练、改指标或重新选择测试阈值。

**本项目并非只测过AnyPPG。** 第一阶段腕部PoC比较三个PPG基模和一个通用时序基模；第二阶段按用户指定，聚焦AnyPPG、CNN和传统对照。更早PPG-Bench还评过PaPaGei-P及SigmaPPG。当前较有支持的收益是少标签HR、AnyPPG的短窗PRV一致性和相对小CNN的质量分类；尚不支持“PPG基础模型全面优于传统方法”，也未建立面向Apple式健康任务、超出已知协变量的增量证据。

## 这些模型为何被选中

第一阶段讨论稿事前提出的组合兼顾可运行性与方法差异：AnyPPG代表ECG引导预训练，PaPaGei-S代表形态感知表征，Pulse-PPG代表野外腕部预训练；MOMENT检验专用PPG预训练相对通用时序表征是否有价值。CNN、峰检测、频谱及训练均值避免只与弱对照比较。已有权重、可验证适配与有限本机计算量使这组组合适合首轮PoC。[原讨论稿](ppg_evaluation_poc_plan.md)

这是一组有依据的代表性子集，不是穷举所有候选后得到的公认最优名单。没有证据支持SigmaPPG或PaPaGei-P因性能差、无法加载或硬件不可运行而被排除；它们没有进入这轮缩小后的矩阵。

AnyPPG进入第二阶段有三个具体原因：第一阶段域内HR及少标签结果在三个PPG模型中较强；用户随后明确要求沿用AnyPPG/CNN/传统算法；已有六层时序特征可以接提点小头。接口便利并不证明其他模型不能提点，也不能用HR排名替代PRV、SQI或疾病任务排名。

这里存在需要保持透明的研究顺序：先看第一阶段结果，再聚焦AnyPPG扩任务。它适合探索性PoC，但不能将第二阶段收益扩大为整个基模类别的确认性结论。第一阶段其他模型结果全部保留；第二阶段模型和阈值仅用训练/验证人选择，不等于把第一阶段测试标签拿来训练第二阶段模型。

特别值得补入的是**PaPaGei-P**：它同样使用同人不同采集片段作为对比正样本，方法思想比只选择AnyPPG更接近Apple 2024的人级表征路线。它仍是独立模型，临床训练数据、架构和输入均不同，不能称Apple复现。SigmaPPG则补充掩码重构路线。[PaPaGei原文§3.1](https://arxiv.org/html/2410.20542v2)、[SigmaPPG原文](https://arxiv.org/html/2601.21031v1)

## 现有结果支持什么

### 心率的完整模型结果

下表为受试者等权MAE，单位bpm，越低越好。均为8秒窗口；基模冻结后接Ridge。3人预算包括2名拟合人和1名验证人，不是总共只标注几分钟。

| 方法 | DaLiA 全预算 | Wild 全预算 | DaLiA 3人 | Wild 3人 | DaLiA到Wild |
| :--- | ---: | ---: | ---: | ---: | ---: |
| AnyPPG | 7.88 | 11.18 | 9.52 | 11.58 | 17.72 |
| PaPaGei-S | 14.43 | 13.62 | 17.02 | 14.00 | 19.30 |
| Pulse-PPG | 10.49 | 12.02 | 12.38 | 12.61 | 18.87 |
| MOMENT-1-small | 8.63 | 12.63 | 10.50 | 13.18 | 16.00 |
| 小型CNN | 7.24 | 11.50 | 11.46 | 14.45 | 15.87 |
| Elgendi式峰检测 | 10.45 | 16.46 | 10.45 | 16.46 | 16.46 |

传统方法无需拟合，复用同一输出；Wild覆盖99.13%，其MAE为可输出窗口上的条件误差。其余所列方法覆盖100%。配对比较使用共同有效窗口。[数值来源](results/ppg_hr_poc/summary.csv)、[配对区间](results/ppg_hr_poc/paired.csv)

**少标签收益最清楚。** AnyPPG相对CNN在DaLiA/Wild的3人预算下分别减少1.94 bpm [0.50, 3.43]、2.87 [1.65, 4.30]。Pulse-PPG在Wild也减少1.84 [0.64, 3.16]，因此不能说只有AnyPPG出现少标签收益。AnyPPG跨两份数据的方向更一致；PaPaGei-S没有同样稳定的证据。

**全预算优势有限。** AnyPPG在DaLiA比CNN高0.64 bpm [0.03, 1.28]；Wild低0.32，但区间为[−1.04, 0.48]，不足以支持稳定领先。PaPaGei-S和Pulse-PPG在当前冻结线性接口下也未超过CNN。该结果评价的是指定适配方式，不是模型经过全部优化后的性能上限。

**跨域没有体现可靠优势。** AnyPPG的迁移点估计17.72不仅高于CNN15.87，也没有低于训练均值对照17.36；不能将其描述为“天然解决域迁移”。事后诊断发现额外误差主要集中在低HR、低ACC场景，但设备、人群、佩戴和预处理的因果贡献尚未分离。AnyPPG迁移相对Wild域内拟合的差为6.53 bpm，这和其相对CNN迁移的差1.84 bpm是两种不同比较。

### 逐搏 PRV与信号质量

| 评价 | 当前证据 | 不能推出的结论 |
| :--- | :--- | :--- |
| 人工PPG起始点F1 | Any/CNN/传统为0.9790/0.9747/0.9662；Any相对CNN差的区间跨0 | 所有基模都能更精确提点 |
| 成功匹配相邻间期MAE | 15.96/15.92/15.68 ms；传统条件误差略低但覆盖也低 | 平均HR更准就代表逐搏时刻更准 |
| 60秒RMSSD误差 | 19.13/36.07/38.32 ms；Any在共同窗口配对比较有收益 | 临床ECG HRV已验证，或强运动普遍有效 |
| BUT质量分类AUROC | 0.8723/0.8340/0.8528；Any优于CNN，相对手工特征区间跨0 | 腕部波形形态质量或去噪能力已验证 |

人工提点评测只有7人、单训练种子，175个PRV窗口中159个为静息。PRV是相对单专家PPG标注的算法一致性，不是ECG HRV。精细定位误差相近而PRV误差下降，提示收益可能主要来自减少漏搏、误检及其对间期序列的破坏；这仍需错误分解或消融确认。[第二阶段结果与支持范围](ppg_phase2_results.md)

质量分类是手机指端/耳部PPG的HR可读性标签；手工特征的平衡准确率和F1点估计还略高。它说明表征具有可用性，同时说明精心设计的传统特征仍是强对照。

### 已有血压结果及其边界

更早PPG-BP线性评测的收缩压MAE分别为AnyPPG13.32、PaPaGei-S14.92、PaPaGei-P14.60、Pulse-PPG13.77、SigmaPPG14.95 mmHg。它们来自218人、654条短指尖PPG，证明这五个模型版本已实际评测；不是手表血压或PulseDB/AAMI评测。部分疾病标签分类接近随机，不能把“跑过疾病任务”当成筛查有效。[已审计完整结果](results/ppg_bench_ppgbp_linear/summary.csv)

所有探索性区间均未做多重比较校正。架构、预处理、采样率和任务头也不完全相同；例如Any逐搏头26,737参数加冻结骨干，对照CNN17,353参数。当前比较支持方法组合的实用表现，尚未把增益单独归因于预训练。

## Apple 2024论文真正回答的问题

用户所指的是ICLR 2024的 **Large-scale Training of Foundation Models for Wearable Biosignals**，采用2024年3月的v2；不是2025年的PpgAge，也不是WBM。[Apple官方入口](https://machinelearning.apple.com/research/large-scale-training)

Apple的关键条件是约14.1万人、1,985万段低运动四光路绿PPG，每段60秒；分别训练PPG与ECG编码器。正样本取自同一人的不同片段，学得的PPG表征按人汇聚后再做线性探测。主要比较对象是人口学信息与心率统计，目标是健康相关信息，不是峰检测误差。[原论文§3–4及图1](https://arxiv.org/html/2312.05409v2)

| 读论文时容易混淆之处 | 应采用的解释 |
| :--- | :--- |
| 同时讨论PPG和ECG | 分别预训练，不能当成AnyPPG式ECG引导PPG跨模态训练 |
| 60秒输入 | 下游每人多个片段表征取均值，不代表单个60秒就达到全部人级结果 |
| 健康分类胜过基线 | 对照是人口学与HR统计，不是完整传统HRV/形态算法竞赛 |
| 高血压或房颤任务 | 自报病史标签，不是连续血压mmHg回归或当前房颤事件检测 |

例如其高血压史、糖尿病史AUC分别为0.819、0.866，基线为0.770、0.804；年龄MAE3.19对6.60岁的差异来自两种正样本选择，双方都经过自监督预训练。作者将表征与HRV等指标的关系列为后续研究。文中没有直接报告去噪重建、逐搏F1、HRV测量误差或下游少标签曲线。原传感数据受知情同意限制，本次官方入口也未找到直接下载的预训练权重。[Table 2/9、§6与复现说明](https://arxiv.org/html/2312.05409v2)

**对本项目的含义是要分别检验测量能力和健康信息价值。** 一个表征即使没有降低每个脉搏的时间误差，也可能保留对健康标签有用的形态、血管或长期个体差异；这些信息是否真实存在、是否超出人口学混杂，需要另做下游验证。反过来，当前少标签HR或PRV有收益，也不足以推导疾病筛查有效。

Apple的表征与人口学/HR基线比较，并不等于已完成“协变量加传统特征加表征”的全部条件增量检验。下文提出的组合对照是本项目可进一步采用的更严格问题，不把它当成原论文已经验证的结果。

同人不同片段的训练目标偏向稳定的个体信息，这是把PaPaGei-P加入后续健康表征比较的理由；它不意味着模型必然丢失瞬时HR，也不意味着这类预训练天然适合逐点时序输出。不同能力必须由对应参考标签裁定。

Apple的低运动、多通道、长历史汇聚与本项目运动场景、单通道、8秒窗口差异很大。数据人数、有效历史、传感器输入和任务标签均不同，不能将本地结果与Apple论文数值作模型排名，也不能把本地没有全面胜出解释为Apple结论被推翻。

## Google和WBM对结果解释的帮助

| 工作 | 编码器输入 | 本项目可以借鉴什么 |
| :--- | :--- | :--- |
| Google LSM | 26个分钟级派生特征，5小时 | 标签效率、缺失数据、固定适配预算对照 |
| Google SensorFM | 34个分钟级特征，24小时；下游还汇聚多天 | 多任务健康信息增量、工程特征与表征的同协议比较 |
| Apple WBM | 27个HealthKit指标，小时聚合、整周 | 行为与PPG表征互补、长期覆盖率和缺失模式 |

这些模型已经使用设备提取的HR/PRV等指标，建模对象是派生时序；相关结果不能直接作为原始PPG去噪或提点更准的证据。[LSM](https://arxiv.org/html/2410.13638v1)、[SensorFM](https://arxiv.org/html/2605.22759v3)、[WBM](https://arxiv.org/html/2507.00191v1)

**LSM尤其说明适配方式会改变结论。** 活动识别准确率为冻结线性探测49.4%、随机初始化监督模型53.2%、完整微调68.5%；附录的小卷积探针在同一660万小时预训练条件下达到67.6%。这支持在评价冻结表征时增加受控小头，而不是把Ridge结果当成模型能力上限，也不要求我们马上开展基模预训练或全量微调。[LSM表3与表10](https://arxiv.org/html/2410.13638v1)

SensorFM报告35个任务中34项优于工程特征监督基线；它展示的是广泛任务上的表征价值，不能把比较对象扩大为所有专用算法。其少标签比例实验与本项目少受试者预算的口径不同，结果方向可以讨论，不能称直接复现。[Google官方介绍](https://research.google/blog/sensorfm-towards-a-general-intelligence-and-interface-for-wearable-health-data/)

WBM提供互补性的例子：糖尿病AUROC中PPG为0.829、WBM为0.765、融合为0.828；睡眠时长R²中分别为0.110、0.590、0.601。没有单一表征在所有任务胜出，融合也非每项都提高。对本项目，更有价值的问题是“表征在已有生理指标之外增加了什么”，而非要求它替代全部传统指标。[WBM表2](https://arxiv.org/html/2507.00191v1)

这些工业模型目前不能当作本仓已接入的开源对照：WBM明确声明代码和权重不能公开，LSM/SensorFM本轮所核官方入口未找到可直接加载的原作者权重。第三方复现与原作者模型应分别标注。

## 下一步应怎样补齐论证

**第一，补齐模型矩阵而不是先扩预训练。** 在现有可靠数据和固定split上，把PaPaGei-P/S、Pulse-PPG、SigmaPPG纳入同协议HR及完整SQI；对已完成对象直接复用。逐搏/PRV先补一个方法路线不同、时序特征可验证的模型，再扩大。未测的格子必须标“未评”，不能当成落后。

**第二，补受控适配与消融。** 保留冻结线性探测为统一基线，另加参数预算相近的小MLP或时序头；比较原生上下文与短窗时，固定中心任务标签与测试样本，不能把更长时间平均HR当成同一个任务。AnyPPG补同架构随机冻结骨干加相同头，以检验预训练特征的贡献；它仍不能替代充分训练的监督CNN对照。PRV优先增加种子与独立人工腕部数据，当前7人结果保留探索性定位。

**第三，增加一个Apple式的健康信息增量任务。** 先确认可靠标签、足够受试者、标签时间与预训练暴露，再固定一个目标；暂不把多个小样本疾病标签一起包装成筛查平台。年龄可以检验表征，但年龄预测本身不能证明血管年龄或未来风险；压力/活动同样不能代替疾病任务。

| 健康任务对照组 | 要回答的问题 |
| :--- | :--- |
| 可用人口学/临床协变量 | 不看PPG，已经可以预测多少 |
| 上述协变量加传统HR/PRV/形态 | 现有生理测量增加多少信息 |
| 冻结PPG表征 | 预训练表征单独能预测多少 |
| 协变量加表征 | 是否超出人口学信息 |
| 协变量加传统特征加表征 | 是否在已有生理信息之上仍有增量 |

各组使用相同人级划分、观察时长和公平的任务头选择预算。年龄若为预测目标，不再作为协变量；由血压直接定义的标签也不能把该血压作为输入。分类同时报告AUROC、AUPRC和校准，回归报告MAE及逐人差值。真正的未来风险预测还需时间先后明确的事件标签，不能用横断面病史分类代替。

图的组织也应跟随证据：保留原单位的跨任务图用于测量能力；加完整模型覆盖矩阵与少标签曲线；等健康任务完成后，再做Apple图1式“基线AUC对表征AUC”或“加入表征后的增量”图。尚未完成的任务不画成分数，也不把bpm、毫秒和AUC归一成一个看似完整的总排名。
