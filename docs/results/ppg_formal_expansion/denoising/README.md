# 合成噪声配对恢复正式评测

2026-11-05。本任务已完成84个小预测器拟合与全部EPFL外部测试；固定协议、训练/验证/测试受试者、20轮上限及验证选轮规则未依据测试结果调整。**结果不支持这两个冻结基模在当前去噪设置下优于小CNN或传统滤波的普遍结论。**

EMBC21取7人的人工标注有效静息PPG，每人24个互不重叠8秒窗口，共168个参考窗口；各叠加−5、5、15 dB的固定随机合成噪声，得到504对。七折每折5人训练、1人验证、1人测试，3个优化种子；同一人的参考与其所有噪声副本不跨角色。参考是有效静息原始PPG，**不保证完全无噪声**。全部输出以64 Hz评分，固定取中央6秒，不根据参考进行增益或时间对齐；推理归一化只使用含噪输入。

比较AnyPPG冻结时序特征加26,737参数预测器、PaPaGei-S冻结时序特征加27,367参数预测器、随机AnyPPG同结构和17,353参数小CNN。四种方法均预测固定0.5–8 Hz滤波输出上的残差；两个基模没有重新预训练或微调。传统对照使用同一个固定滤波器，另保留直接含噪输入。不是将全局向量当成波形，而是使用冻结网络的六层时序特征。

NRMSE是相对参考波形均方根的误差，越低越好；每个窗口分别算指标后按人平均。SNR以对数度量，因此其均值排序不必与平均NRMSE相同。恢复波形的误差改善也不等于心率或逐搏改善。AnyPPG/PaPaGei-S相对小CNN的NRMSE差为+0.204（人级95% CI 0.159至0.247）/+0.168（0.114至0.219）；相对固定滤波为−0.263/−0.300。仅7人的四项确切配对检验经Holm校正均为0.0625，不据此宣称统计确定性；固定共享训练折下区间仍属探索性。

EPFL的340个噪声版本均来自**一个基础采集人/一条72秒参考波形**。每个版本9个互不重叠窗口，共3060对，全部由每种方法的21个已拟合折/种子模型测试，再平均指标；EPFL不参与拟合或选轮、不提供人群置信区间。固定滤波NRMSE 0.239明显低于当前学习输出；AnyPPG、PaPaGei-S相对含噪输入的平均SNR增益分别为−10.76、−12.05 dB，不能把本结果描述为外部去噪成功。噪声分层全部报告，不能只挑高噪声成功片段。

审计从原始采集波形逐一重建504+3060对参考、输入归一化和传统滤波结果，最大差0；EMBC21手工心率参考重算差0、实际噪声能量SNR最大差1.28×10⁻⁷ dB。446个来源文件、30个时序特征数组的哈希核对通过；84个预测器的840组指标数组用独立NumPy公式复算，最大差1.67×10⁻¹⁵；252条CPU波形重建最大差1.91×10⁻⁶。每方法/种子内每个EMBC21测试配对仅出现一次。不能将这些合成噪声结论替代真实腕部运动伪影或临床生理验证。
