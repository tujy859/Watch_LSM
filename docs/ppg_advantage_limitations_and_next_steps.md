## 1. 当前并非所有任务都没有收益

统一16维小MLP下，WildPPG仅2名训练者、1名验证者时，AnyPPG相对CNN减少2.64 bpm，Holm校正p=.00146；同数据集六个场景均优于相同架构的随机冻结Any。DaLiA伪影检测中，Any相对随机Any也有收益，但CNN均值更高。WESAD实验状态分类有部分收益。相反，SDS、血压增量、跨数据集HR及合成去噪没有支持普遍优势。

这些结果表明收益依赖任务、数据和适配方式。“传统算法”本身也不是一个统一模型：心率峰检测、质量手工特征、健康任务的HR/PRV统计和去噪带通滤波所保留的信息不同。小CNN在每个目标上直接学习，而冻结基模只允许最后的小预测器学习；前者有更强的任务适应自由度，后者的优势通常需要通过少标签、迁移或额外信息来检验。

## 2. 与Apple 2024相比，具体差在哪里

论文是[Large-scale Training of Foundation Models for Wearable Biosignals，ICLR 2024](https://machinelearning.apple.com/research/large-scale-training)。Apple采用大规模纵向腕部数据及同人不同片段的自监督学习，重点验证人级健康表征；它没有直接证明波形去噪或逐搏定位更准确。

| 因素 | Apple PPG工作 | 本仓SDS | 能否由当前结果确定影响 |
| :--- | :--- | :--- | :--- |
| 预训练规模 | PPG库141,207人、约1,985万段 | 使用六模型已有权重，来源各异；本轮无预训练 | 无法由不同模型/不同任务的结果隔离预训练规模效应 |
| 下游标注规模 | 抑郁史测试16,457人；训练/验证人数未明确披露 | 60个独立标签，每折36训练/12验证/12测试 | 不应拿Apple预训练人数与本仓下游人数当同一口径 |
| 原始片段与单次编码 | 60秒原始记录、四个绿光空间光路；预训练另有裁剪/遮挡等增强 | 每次编码8秒、单路E4 BVP | Apple增强后的有效上下文未完整披露；硬件和时长未做匹配消融 |
| 每人观察覆盖 | 多日片段；预训练库平均92.54个采集日，下游各任务覆盖未另报 | 一次连续120秒中性刺激 | 两分钟不是多日状态覆盖，不能把预训练平均天数当下游每人固定天数 |
| 人级聚合 | 每人的片段表征取平均 | 15个8秒表征取平均 | 双方都丢弃片段顺序，不能归因于“Apple用了复杂时序聚合” |
| 下游预测 | 原表征接Ridge线性预测器 | 先压到8维，再接Ridge或小MLP | 本仓已有非线性对照，但两种头共用压缩瓶颈 |
| 健康目标 | 包括自报既往抑郁诊断的二分类 | SDS连续自评分数 | 不是同一标签、同一人群或同一指标 |
| 主要对照问题 | 表征单独与人口学＋HR均值/标准差比较 | 人口学＋传统特征＋表征，对人口学＋传统特征 | 本仓条件增量问题更严格，不能直接对标论文AUC |

上述协议来自[论文§4.1–4.3及附录](https://arxiv.org/html/2312.05409v2)。预训练划分比例不能代替未明确披露的下游训练/验证人数；本次未找到下游PCA或Ridge搜索的完整细节。

对本项目的启示是：先检验现成表征在合适观察尺度上能否贡献额外健康信息。论文支持这一研究方向，不保证单路、一次短观察能预测SDS。它也不能支持“换成更大的预测器就会好”的推论。同人不同片段学习强调稳定的人级信息，而逐点重建要求保留幅度、相位和细节，二者的目标未必一致；这是需要实测的机制假设。

## 3. SDS：目前主要是在预测人群中心值

### 3.1 先看常数对照，再谈模型排名

| 方法 | SDS MAE，越低越好 |
| :--- | ---: |
| 每折训练者平均分 | 7.0683 |
| 每折训练者中位分，本轮只读诊断 | 6.9375 |
| 人口学＋传统特征，线性 | 6.9166 |
| 上述对照＋PaPaGei-P，线性 | 6.8419 |
| Any表征单独，线性 / 小MLP | 7.1307 / 6.9944 |
| 随机Any表征单独，线性 / 小MLP | 7.0203 / 7.2540 |
| Sigma表征单独，线性 / 小MLP | 6.8615 / 6.7861 |
| 小CNN单独 | 6.9815 |

中位分对照只读取每折训练人的标签，未重新拟合模型，未替换正式主对照。它特别适合帮助解释MAE，因为训练样本的中位数最小化训练集常数绝对误差。表中不同输入组不能混成同一个“增量排名”。

传统线性相对中位分只低0.0209分。PaPaGei-P融合相对传统低0.0747分，配对95%区间为−0.7966至+0.7518，Holm p=1；其RMSE还从8.5969升到8.9053。没有证据确认有稳定的实际收益；也没有足够精度排除所有中小幅收益。

真实SDS标准差8.385分，Any线性表征预测的跨折标准差只有1.283分，传统线性预测也只有2.292分。预测分数的跨人差异明显压缩。不能仅凭MAE接近常数就严格断言没有个体排序信息，但目前分数差异的恢复明显不足。

### 3.2 数据规模：瓶颈是独立人，不是切片数

60人只有60个SDS标签，15段/人合计900段仍不是900个独立健康样本。三个优化种子不改变这五折的人群划分，也不增加独立样本量。全部主输入总共两小时。

人群18–28岁，34/60集中在24–25岁；19男、41女。SDS均值44.54，中位42.50，范围28.75–66.25。人群覆盖有限、标签范围和生理关联可能较弱，是合理解释；但我们没有重复量表或外部临床参考，不能量化标签噪声上限，也不能断言PPG本身不含相关信息。

**预训练规模与下游标注规模必须分开。** 更丰富的无标签预训练可能提升表征；它不自动解决36名训练者下的预测器估计、混杂和外推问题。反过来，增加同一60人的重复片段可以改善观察，却不能替代增加独立受试者。

### 3.3 输入时长：两个不同问题

实际链路为：连续120秒 → 15个8秒编码 → 片段表征算术平均 → 标准化与PCA8 → 分数预测。

因此应区分：

1. **每次编码看多长**：现在只有8秒。它含局部脉搏信息，但不能直接建模跨片段的间期变化。
2. **每个人总共观察多久、多少次**：现在只有一次120秒。平均15段能减少部分局部波动，不等于覆盖日间、睡眠、活动及多日状态。

传统对照另计算完整120秒上的HR/间期统计，包括RMSSD。因此双方观察了同样时间，保留的时间结构并不相同。不能把这个差别解释成传统方法“天然更懂健康”，也不能认定片段平均一定错误；Apple本身就使用平均聚合。

现有原始metadata允许所有60人使用至少232秒的同一中性段，可比较120秒与232秒，保持8秒编码不变。这能隔离**观察量**，但不能检验多日覆盖，也不能检验单次编码60秒的效果。后者需要单独验证各模型的长度支持和时间特征接口，不能简单补零或拉伸8秒波形。

### 3.4 预测器设置：8维不是相同信息量

PCA是按训练人特征方差保留方向的降维，未使用测试数据；它不保证保留最有利于SDS的方向。本轮从保存的矩阵重算，PCA8保留的训练特征方差为：Any78.40%、PaPaGei-S85.53%、PaPaGei-P67.19%、Pulse87.14%、Sigma69.65%、MOMENT94.37%，随机Any约94.10%–94.74%。

统一维度控制了小预测器的输入容量，却对不同模型压缩了不同比例的信息。**方差不等于预测信息**，所以这些数值提示应做消融，不能证明丢弃的方向包含SDS信号。已有MLP同样只接收PCA后的输入，无法恢复已丢弃的方向。

更大的头或更久的训练不是当前首选：

- 345份MLP拟合，最佳验证轮次中位数3，149份在第1轮，204份在前5轮；只有1份在第100轮。
- Any表征MLP第100轮的验证MAE平均比最佳轮高6.07分。
- 六个预训练模型、五折的30个表征单独线性设置中，19个选择最大正则强度1000，24个选择至少100。

这些现象更符合需要强正则、验证样本少及后期过拟合的解释。没有完整逐轮训练损失记录，不能据此完全排除优化设置问题。健康预测器名义为51参数线性、833参数MLP；补零和常数缺失标记不增加有效变化信息，也不能把名义参数全部当成实际有效输入连接。

## 4. 去噪：先处理评测问题，之后才能谈模型能力

### 4.1 新确认的参考构造缺陷

在`scripts/ppg_formal_denoising.py`的`prepare()`中，EMBC原始ADC信号带有较大的直流偏置，先调用默认零延拓的`resample_poly`，随后才去均值。窗口外的零与原信号产生跳变，被滤波重采样变成边界瞬变；事后去均值无法消除它。

168个独立参考窗口的复核结果：

- 原始直流绝对值中位6260，波动标准差中位47.18，二者比值中位118.52。
- 旧参考重采样后全窗RMS中位86.51；仅诊断性地改为先去直流再重采样，则为47.03。
- 两种参考的全窗差平方和相对旧参考平方和，平均为61.54%；**不是说中央评分区有61.54%的失真**。
- 中央6秒参考差的NRMSE均值约0.039；经过既有带通后，输出差增至约0.438。边界误差会影响后续滤波。
- 合成噪声幅度又依据被污染的全窗能量确定。名义15 dB组在实际中央6秒的输入SNR平均仅9.71 dB；这些口径不能混用。

独立线性核验表明，旧参考与先去直流参考之差，等于“原直流值×重采样全1序列的去均值响应”，168窗最大残差1.44×10⁻¹¹。这确认了来源，不只是根据图形猜测。

因此旧EMBC训练参考和噪声条件需要新版本重建；依赖这批训练头的EPFL外部结果也应重新评价。原预测可以复算，但不能继续作为有效去噪能力排名。本轮只做CPU数据诊断，没有用修正输入训练或发布新模型分数；没有将这一发现自动推广为其他任务也存在同样问题。

### 4.2 目标与输入保留的信息不同

另一个独立问题是：目标是**只去直流、仍含低频变化的静息参考**，固定基线却只保留0.5–8 Hz。所有学习方法输出“固定带通＋学习残差”，但残差的输入不一样：

| 方法 | 残差预测器能读取什么 |
| :--- | :--- |
| CNN | 未带通的带噪波形，按带噪窗口均值/标准差归一化 |
| Any与随机Any | 0.5–8 Hz带通并再次标准化后的冻结时序特征 |
| PaPaGei-S | 官方带通、平滑并标准化后的冻结时序特征 |

基模残差头没有直接读取未滤波波形、原归一化尺度或滤波前后尺度比。预测器参数接近不代表可用信息相同。CNN可以学习利用部分基模输入已被削弱的信息；基模头还要从下采样的特征重建逐点幅度。因而CNN胜出不能单独归因于“预训练无用”。Any对随机Any虽然共用预处理，比较更接近预训练消融，但同样受有问题的参考任务约束。

即使先去直流再重采样，参考不加合成噪声、仅过现有带通，中央NRMSE仍约0.764；旧处理为0.922。这说明修边界还不够，需要事先说明恢复目标究竟是完整AC波形还是规定频带内的脉动成分。不能为使某方法赢而事后修改参考滤波规则。

### 4.3 已有输出呈现幅度收缩与分布迁移问题

以下只是**旧协议诊断**，不是有效能力榜单。名义15 dB组（实际中央SNR不同）中：

| 方法 | NRMSE，低为好 | 预测/参考标准差比 |
| :--- | ---: | ---: |
| 不处理，直接用带噪信号 | 0.354 | 1.076 |
| 固定带通 | 0.937 | 0.743 |
| Any | 0.850 | 0.668 |
| PaPaGei-S | 0.814 | 0.538 |
| CNN | 0.521 | 1.039 |

在这一较低噪声组，所有处理都比不处理误差大。Any全体平均NRMSE1.016，而恒零输出按当前指标定义恒为1；这不表示每个窗口都劣于零波形，但提示不能只看相对严重带噪输入的改善。

EPFL输入SNR至少20 dB的窗口中，Any/PaPaGei-S输出与参考相关约.953/.958，标准差比却仅.643/.553。高相关不等于正确幅度。数据源、参考低频结构和人工噪声不同，也能解释为何EMBC与EPFL的方法排名反转；尚未完成能拆分这些原因的干预实验。EPFL始终只有一个原始人，340份噪声副本不能产生340人的外部证据。

训练参考的多样性也很有限：每折5名训练人、120个独立8秒参考窗，合计16分钟；三个噪声副本不是三倍独立生理数据。8秒仅覆盖注入0.1–0.4 Hz漂移的0.8–3.2个周期，更长上下文值得在修正协议后验证。当前基模头确实读取多层时序特征，包括浅层，不能把它描述成仅从一个全局向量还原波形。

训练不足也不是所有方法的统一解释：Any的21次拟合均未到20轮上限就按验证停下，PaPaGei-S有3次最佳在上限、CNN有11次。应分别检查收敛，不应只给基模增加训练时间。先修数据和信息路径，之后再决定是否调整训练轮数。

## 5. 下一步按什么顺序验证

下表是建议，**本轮未启动**。所有建议继续冻结现有编码器；必要的小预测器拟合与基模预训练是两回事。

| 顺序 | 最小验证 | 固定什么、改变什么 | 可回答的问题 |
| :--- | :--- | :--- | :--- |
| 1 | 去噪参考修复与保真检查 | 新目录/新协议；先去直流、明确延拓/有效区和目标频带；加入不加噪、低噪、不处理、零输出对照 | 原任务是否奖励恢复真实目标，能否保持干净输入 |
| 2 | 去噪输入信息一致的对照 | 同一轻量原波形支路，分别加预训练特征、随机特征或不加特征；尺度信息一致；训练/验证人和搜索次数一致 | 冻结基模是否为小波形网络带来额外价值 |
| 3 | SDS去掉强制8维压缩 | 先复用缓存；同一120秒/均值聚合，比较PCA8-Ridge与原维强正则Ridge | 阴性结果是否被特征压缩限制 |
| 4 | SDS延长总观察量 | 8秒编码与均值聚合不变，120秒对232秒；传统与CNN同步使用相同时间 | 多观察近两分钟是否改善个体预测 |
| 5 | SDS聚合与编码时长分别验证 | 固定120秒，先比较均值与少量波动/变化摘要；单次编码长度另做兼容性验证 | 信息在短窗编码、聚合还是观察覆盖处受限 |

SDS的第3步计算便宜，可保留全部六模型和随机Any，避免事后只挑最高分模型；统一Ridge选参次数，维度高时依靠正则而非无限扩头。只增加一个新的预测器设置即可，不必把维度、层数、学习率和时长做大规模组合搜索。若资源必须缩减，预先锁定代表模型并注明探索性，不按测试排名挑选。

去噪第2步建议把基模视为给小波形网络提供补充特征。预训练和随机分支使用同一结构；无表征支路的参数差异另列，并保留相近容量CNN。这样可以同时测实用收益和预训练贡献，避免让“CNN可见原波形、基模不可见”主导结论。参考频带、归一化、容许的延迟/幅度处理在看新测试结果前确定。

SDS仍报告两个不同问题：表征单独能预测多少，以及加入人口学＋传统特征后还能增加多少。对照包括训练中位分/平均分、传统、随机编码器、CNN；主MAE之外查看RMSE、个体排序和预测幅度，但不因某个辅助指标好看而更换主指标。训练端标签置乱可作为必要时的小型流程检查，不作为提高分数的手段。

这60人已被反复查看，后续消融只能帮助解释机制。若要确认健康增量，应优先获得**独立、健康标签可靠且观察更充分的受试者**，预先确定实际有意义的改善幅度及统计方案，再做样本量评估。不应凭当前结果武断指定“再加多少人一定显著”，也不建议把现有60人不断切窗扩大为虚假的大样本。

若只能先做两件事：**修正去噪协议并保证输入信息一致；SDS用已有表征比较PCA8与原维Ridge。** 这两项最能区分“信息没被保留/读出”和“当前数据下确实未见预训练增量”。在它们完成前，重新预训练、堆大预测器或扩大任务数量都不是最高优先级。
